Build 2D games

Pyngine adalah game engine 2D ringan berbasis Python yang dirancang untuk membuat game dengan workflow sederhana, modular, dan mudah dipahami.

Get Started Create a Project
PY

Python First

Gunakan Python sebagai bahasa utama untuk membuat gameplay dan scripting.

2D

2D Focused

Fokus pada workflow game 2D tanpa kompleksitas engine besar.

⚡

Lightweight

Dibuat dengan dependency yang sederhana dan mudah dijalankan.

Installation

Pyngine membutuhkan Python 3.12 atau versi yang lebih baru.

1. Clone repository 

git clone https://github.com/yourusername/pyngine.git
cd pyngine

2. Install dependencies 

pip install -r requirements.txt

3. Check installation 

python main.py version

Your First Project

Buat project Pyngine baru menggunakan CLI. 

python main.py create MyGame

Struktur project yang dibuat: 

MyGame/
├── project.json
├── scenes/
├── assets/
├── scripts/
└── build/

Untuk membuka project menggunakan editor: 

python main.py editor MyGame

Project System

Setiap game Pyngine memiliki file project.json sebagai konfigurasi utama. 

{
    "name": "My Game",
    "engine_version": "0.1.0",
    "window": {
        "width": 1280,
        "height": 720,
        "fps": 60
    },
    "main_scene": "scenes/main.json"
}

Scenes

Scene adalah tempat GameObject dalam game disimpan. Scene menggunakan format JSON sehingga mudah dibaca dan diproses. 

{
    "name": "MainScene",
    "objects": [
        {
            "name": "Player",
            "components": []
        }
    ]
}

GameObjects

GameObject adalah objek dasar dalam scene. Setiap object dapat memiliki berbagai component. 

player = GameObject("Player")

player.add_component(
    SpriteRenderer("player.png")
)

player.add_component(
    Collider()
)

Components

Component digunakan untuk memberikan kemampuan tertentu kepada GameObject.

Component Purpose
Transform Position, rotation, dan scale
SpriteRenderer Menampilkan sprite
Collider Collision detection
RigidBody2D Physics dan velocity
Animator Sprite animation
Camera2D Camera system
AudioSource Sound dan music
Script Gameplay logic

Sprites

Pyngine menggunakan SpriteRenderer untuk menampilkan gambar dalam game. 

sprite = SpriteRenderer(
    "assets/player.png"
)

player.add_component(sprite)
Resource caching

Texture dan asset tidak dibaca ulang dari disk setiap frame. Resource Manager menangani caching.

Input

Gunakan Input Manager untuk membaca keyboard dan mouse. 

if Input.is_key_pressed("A"):
    player.move_left()

if Input.is_key_pressed("D"):
    player.move_right()

if Input.is_key_down("SPACE"):
    player.jump()

Physics

Physics system menyediakan gravity, velocity, collision, rigid body, dan trigger. 

player.add_component(
    RigidBody2D()
)

player.add_component(
    Collider()
)

Collision 

def on_collision(self, other):
    print("Collision with:", other.name)

Camera

Camera2D digunakan untuk mengontrol tampilan world dan mengikuti object tertentu. 

camera = Camera2D()

camera.follow(player)

Audio

Gunakan Audio Manager untuk memainkan music dan sound effect. 

Audio.play_music(
    "assets/music/theme.ogg"
)

Audio.play_sound(
    "assets/sounds/jump.wav"
)

UI

Pyngine menyediakan komponen UI sederhana untuk kebutuhan game. 

button = Button(
    text="Play",
    on_click=start_game
)

ui.add(button)

Python Scripting

Gameplay dapat dibuat menggunakan Python. 

class PlayerController:

    def update(self, delta):

        if Input.is_key_pressed("A"):
            self.move_left()

        if Input.is_key_pressed("D"):
            self.move_right()

Editor

Pyngine Editor menyediakan interface visual untuk mengelola scene dan GameObject.

H

Hierarchy

Melihat semua GameObject dalam scene.

V

Viewport

Melihat dan mengatur object dalam world.

I

Inspector

Mengedit properties GameObject.

Command Line

Pyngine menyediakan CLI untuk workflow development. 

python main.py create MyGame

python main.py editor MyGame

python main.py run MyGame

python main.py build MyGame

python main.py version

Build & Export

Gunakan build command untuk membuat versi game yang siap dijalankan. 

python main.py build MyGame

Output akan dibuat di folder: 

build/
└── MyGame/
